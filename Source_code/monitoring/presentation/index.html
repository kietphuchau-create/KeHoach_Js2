CHỈ SỐ TIÊU CHUẨN

4 Nhóm Chỉ Số Vàng SRE Được Đo Lường

Tiêu Chuẩn Giám Sát Quốc Tế
1. HTTP & Độ Trễ P95

Đo đếm request và thời gian phản hồi.

  • • Tổng số lượt gọi API
  • • Phân loại mã 200, 4xx, 5xx
  • • Độ trễ P95 dưới 10ms
2. RAM JVM Heap

Theo dõi bộ nhớ Java Runtime.

  • • Mức RAM cấp phát & sử dụng
  • • Tần suất dọn rác GC Pause
  • • Chống tràn bộ nhớ OOM
3. Tải CPU Vi Xử Lý

Hiệu năng xử lý thuật toán.

  • • % CPU tiêu thụ của App
  • • Tải tổng thể máy chủ Cloud
  • • Luôn duy trì mức thấp < 5%
4. Hồ Kết Nối HikariCP

Sức khỏe kết nối CSDL MySQL.

  • • Active Connections
  • • Idle Connections rảnh rỗi
  • • Chống nghẽn truy vấn SQL

Thuộc tính exposure.include công khai endpoint qua giao thức web. Mặc định Spring Boot ẩn đi để bảo mật, cần mở tường minh cho Prometheus cào.

Tự động đóng dấu nhãn application="medsched" vào từng dòng số liệu xuất ra, giúp phân biệt rõ ràng khi chạy chung cụm với các dịch vụ khác.

Cho phép máy chủ Prometheus cào số liệu mà không bị chặn lỗi 401 Unauthorized, do bot cào chạy ngầm không có phiên đăng nhập của người dùng.
