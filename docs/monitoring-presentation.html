Mã Nguồn & Cấu Hình Dự Án

Chi Tiết Tích Hợp Prometheus & Grafana

Vị trí chính xác các file cấu hình backend Spring Boot, phân quyền JWT và hạ tầng Docker.

📦 1. Nạp Thư Viện Đo Lường
Source_code/backend/app/build.gradle (L23-25)
// Thư viện thu thập số liệu và biên dịch định dạng Prometheus TSDB implementation 'org.springframework.boot:spring-boot-starter-actuator' implementation 'io.micrometer:micrometer-registry-prometheus'
  • Actuator: Đo lường nội tại Spring Boot: JVM Heap RAM, CPU tiến trình, HTTP Request, HikariCP Pool.
  • Micrometer Prometheus: Xuất số liệu theo định dạng chuỗi thời gian (TSDB) cho Prometheus cào.
⚙️ 2. Bật Endpoint & Gắn Nhãn Metrics
backend/app/src/main/resources/application.yml (L104-117)
management: endpoints.web.exposure.include: health, info, prometheus, metrics endpoint.prometheus.enabled: true metrics.tags.application: medsched
  • exposure.include: Mở cổng xuất số liệu HTTP tại đường dẫn /actuator/prometheus.
  • metrics.tags.application: Gắn nhãn application="medsched" giúp Grafana lọc số liệu chính xác khi scale.
🛡️ 3. Phân Quyền Bảo Mật JWT
com/medsched/security/SecurityConfig.java (L66-78)
// Cho phép /actuator/** truy cập công khai để Prometheus cào định kỳ .requestMatchers( "/", "/health", "/api/v1/health", "/actuator/**", // <-- Prometheus cào metrics tại đây "/api/v1/auth/**" ).permitAll()
  • Mặc định Spring Security chặn toàn bộ API nếu không có JWT token (trả về 401 Unauthorized).
  • Cấu hình permitAll() cho /actuator/** giúp Prometheus cào 24/7 mà không làm lộ dữ liệu y tế của bệnh nhân.
🐳 4. Cấu Hình Cào Cloud & Docker Grafana
Source_code/monitoring/ (prometheus.yml & docker-compose)
- job_name: 'medsched-cloud-render' # Cào từ Render Cloud thật (HTTPS:443) metrics_path: '/actuator/prometheus' static_configs: - targets: ['medsched-zu15.onrender.com:443']
  • scrape_interval: 5s: Cứ 5 giây Prometheus chủ động gửi HTTP GET kéo số đo về lưu vào kho TSDB.
  • ports: ["3100:3000"]: Ánh xạ Grafana sang cổng 3100 tránh đụng độ Next.js; tự nạp Dashboard qua provisioning/.
